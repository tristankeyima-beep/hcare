# “让我来帮忙”文字图生视频提示词

以头帧图片作为起始画面，以尾帧图片作为最终收尾定格画面，生成一段适合慢病管理系统 AI 健管师入口 hover 状态的卡通文字动效。文字样式严格参考尾帧：软糖感 3D 立体中文大字，白色厚描边，蓝色与绿色渐变，高光明亮，轻微投影；上排是“让我”，下排是“来帮忙”，其中“让我”和“帮忙”为蓝色系，“来”为绿色系。画面只保留透明底上的文字和小装饰，不要添加人物、背景、额外文案或水印。

动画要求：从头帧开始，文字整体从左下方轻轻弹入，先略小、略透明，然后逐个字快速放大到尾帧位置；“让”“我”先出现，“来帮忙”随后跟上，形成轻快的弹性停靠。左侧蓝绿色短线装饰向外轻轻散开，右侧绿色小爱心和黄色星星轻微漂浮后稳定。整体节奏活泼、可爱、阳光，动作幅度小，适合 UI hover 微交互。

收尾要求：最终画面严格贴近尾帧，文字“让我来帮忙”完整清晰、无错字、无缺字，厚描边和立体阴影稳定，透明背景干净。最后定格 1.5-2 秒，方便和右侧 AI 健管师小护士 hover 形态衔接。

负面要求：不要改变文字内容，不要出现错字、乱码、缺笔画、标点或英文；不要生成气泡框、对话框、复杂背景、真实照片风、过度旋转、强烈透视、闪烁、抖动、拉伸、裁切、水印或多余图形。
