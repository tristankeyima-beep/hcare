# AI 健管师 IP 文件夹说明

## 目录结构

- `01_提示词`：IP 形象、首页海报、视频动效相关提示词。
- `02_IP形象_透明底`：页面可直接使用的透明底 IP 形象资产。
- `03_IP形象_抠图底原图`：用于重新抠图或二次处理的纯色背景原图。
- `04_首页海报`：agent 首页海报图。
- `05_历史展示图`：早期展示版、带背景版或非透明底版本。
- `06_文字动效_让我来帮忙`：“让我来帮忙”文字头尾帧与视频提示词。
- `99_待复核`：暂存需要重新检查或修复的文件。

## 当前可用透明底形态

- 形态 1：半身入口态
- 形态 2：查找资料中
- 形态 3：电脑工作中
- 形态 4A：查找资料完成态
- 形态 4B：电脑工作完成态
- 形态 5：agent 首页准备开干态

## 备注

透明底图用于页面叠放；抠图底原图用于后续重新去背、修边或生成视频首帧。
