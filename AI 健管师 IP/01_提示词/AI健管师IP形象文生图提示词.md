# AI 健管师 IP 形象文生图提示词

## 使用目标

为慢病管理系统设计一个 AI 健管师助手形象，放置在页面右上角作为入口。用户点击后进入健管师 agent 首页。

整体形象要求：身穿白色护士服的可爱年轻女性，阳光、温柔、可靠，适合医疗健康管理系统的 B 端页面氛围。


## 生成建议

先用“统一角色设定”生成主形象，选定后把它作为参考图继续生成 5 个形态，这样脸型、发型、护士服和整体气质更一致。

右上角入口建议优先做“白色背景/透明背景、半身、减少细节”，避免在现有系统顶部区域显得太重。
