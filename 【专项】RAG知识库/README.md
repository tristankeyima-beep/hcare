本目录沉淀《中华人民共和国成人体重管理指南（2025）》和《成人肥胖食养指南（2024年版）》接入 Dify 知识库的实验资产，可作为后续慢病管理系统接入医学指南知识库的基线。

- `01_知识库文档/中国成人体重管理指南_2025_Dify清洗版.md`：实际上传至 Dify 的清洗版 Markdown，也是后续迭代的唯一内容源。
- `01_知识库文档/成人肥胖食养指南_2024原始PDF.pdf`：原始指南；对应的三个正式 Markdown 分册为实际上传内容。

- `03_测试与调试/测试与调试手册.md`：Dify API 测试、排障和复现方法。
- `03_测试与调试/检索测试集.md`：面向医学指南的基线问题集与验收标准。

## 已验证的导入方案

文档模式选用**父子分段**：父分段保留章节、表格和上下文；子分段作为实际检索单元。清洗版已移除页眉页脚、作者与英文重复信息、参考文献等噪声，并将表 1–7 转为 Markdown 表格。

| 项目 | 已验证设置 |
| --- | --- |
| 父分段分隔符 | `\n\n` |
| 父分段最大长度 | 1800 characters |
| 子分段分隔符 | `\n\n` |
| 子分段最大长度 | 512 characters |
| 文本预处理 | 替换连续空格、换行符和制表符；不删除 URL/邮箱 |
| 索引 | 高质量 |
| Embedding | `multimodal-embedding-v1` |
| 检索 | 混合检索；权重融合（语义 0.7 / 关键词 0.3）；Top K 4；不设分数阈值 |

## 当前实验结论

1. PDF 不应直接作为长期维护的 RAG 源；经过结构化清洗的 Markdown 对表格、章节和检索上下文更可控。
2. 父子分段中，**子分段负责检索，父分段提供上下文**。因此优化检索命中要优先看子分段，而不是只编辑父分段。
3. “混合检索”下的“权重设置”和“Rerank 模型”是最终排序的二选一策略。本次最终保留权重融合，而非 Rerank。
4. 对表格类问题，用户问法越接近表题、分层名称、指标区间和套餐名称，越容易稳定命中；例如“表4 超重人群 套餐C 运动建议”。
5. 分段关键词可以通过父分段 API 保存，但在父子模式下未改善该表的实际子分段召回；不能把“打标”当成通用提分手段。

详细复现过程、已验证结果和踩坑记录见 `03_测试与调试/测试与调试手册.md`。
