# 慢管系统「管理内核」视频设计

## 目标

为医院和健康管理机构的决策者制作一支 16:9、约 48 秒、无旁白无背景音乐的价值片。视频传达：慢病管理将分散的患者信号转化为可设计、可分层、可规模执行的长期服务。

## 边界

- 仅呈现抽象患者、数据流、病种管理拓扑与执行动作；不伪造完整产品 UI。
- 不使用真实患者姓名、病历或可识别个人信息。
- 真实系统操作录屏留给后续 Screen Studio 操作说明片。

## 视觉语言

医疗科技发布会风格：深海军蓝为基底，雾白信息面板与青绿色信号强调；图形克制、留白充足、一次只表达一个结论。镜头按“多源患者 → 单个患者 → 病种管理模型 → 人群行动网络”的尺度变化推进。

## 节奏与画面

| 时间 | 叙事结论 | 画面 |
|---|---|---|
| 0–4 秒 | 管理不止于收集数据 | 数据光点汇聚成患者与管理路径。 |
| 4–14 秒 | 承接每一种患者来源 | 六类来源驱动患者档案卡片矩阵：院内门诊、出院办理、药房购药、健康管理中心、视频号引流、企业健康小屋。 |
| 14–21 秒 | 画像持续生长 | 一张患者卡片被推近，购药、门诊检查、居家指标与随访等动态在时间轴上更新。 |
| 21–35 秒 | 每个病种都有可运行的管理内核 | 从病种树聚焦到一个病种，以顺时针拓扑依次呈现服务项目、干预方案、分层分标、管理助手 Agent、专属健康顾问 Agent、知识库。 |
| 35–45 秒 | 差异被转化为行动 | 高中低危与红黄绿标患者矩阵被扫描；更新随访、立即干预、饮食方案、运动方案、健康周报等动作形成队列。 |
| 45–48 秒 | 形成长期管理路径 | 所有节点收束为慢管系统核心图标与结语。 |

## 屏幕文案

1. 慢病管理，不止于收集数据
2. 承接每一种患者来源 / 理解每一份数据的完整度
3. 不是一次建档 / 而是持续生长的患者画像
4. 每一个病种 / 都有一套可设计、可执行的管理内核
5. 看见差异 / 并把差异转化为行动
6. 让每一位患者 / 走进适合自己的长期管理路径
