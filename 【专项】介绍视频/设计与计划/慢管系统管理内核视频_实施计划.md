# 慢管系统管理内核视频 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `videos/management-core-demo` 生成可预览的 48 秒 HyperFrames 管理内核价值片。

**Architecture:** 使用一个 HyperFrames 根时间线编排六个 HTML 子场景。每个场景使用抽象数据、SVG 连线与 CSS 信息面板，所有视频视觉均由 HTML、CSS 和 seek-safe GSAP 动画生成；无音频轨。

**Tech Stack:** HyperFrames、HTML、CSS、GSAP、SVG、HyperFrames CLI。

---

### Task 1: 初始化静音视频项目

**Files:**
- Create: `videos/management-core-demo/hyperframes.json`
- Create: `videos/management-core-demo/index.html`
- Create: `videos/management-core-demo/STORYBOARD.md`

- [ ] **Step 1: 初始化空白 1920×1080 HyperFrames 项目**

Run: `npx hyperframes init videos/management-core-demo --non-interactive --example=blank`

Expected: 项目目录和 `hyperframes.json` 存在。

- [ ] **Step 2: 写入六段无声分镜**

Create `STORYBOARD.md` with six scenes timed 0–4, 4–14, 14–21, 21–35, 35–45, and 45–48 seconds; use the approved design specification as the source of truth.

- [ ] **Step 3: 检查项目元数据**

Run: `npx hyperframes info videos/management-core-demo`

Expected: CLI reports a renderable project.

Expected: no structural errors.
