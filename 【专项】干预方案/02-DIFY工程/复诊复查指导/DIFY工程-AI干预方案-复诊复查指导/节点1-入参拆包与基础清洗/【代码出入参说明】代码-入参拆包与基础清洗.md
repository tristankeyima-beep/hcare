# 代码节点：入参拆包与基础清洗

## 输入

- `planType`
- `planGoalAndRequirements`
- `extraSupplement`
- `basicProfile`
- `diseaseProfile`
- `followupRecordsLast1y`
- `metricRecordsLast1y`
- `dietRecordsLast1y`
- `exerciseRecordsLast1y`
- `medPickupRecords1y`
- `activeControlGoals`

## 输出

- `medicalStatusContext`：基础档案、专病档案、近期指标和控制目标。
- `reviewNeedContext`：随访、指标、饮食、运动、取药和目标记录。
- `safetyTriggerContext`：异常指标、疾病背景、随访和用药连续性。
- `planType`
- `routeWarning`
- `inputStats`

## 规则

- 对象和数组入参兼容 JSON 字符串。
- 只做清洗、截断和上下文拆分，不生成业务建议。
- 当前工程默认 `planType=followup_review`。
