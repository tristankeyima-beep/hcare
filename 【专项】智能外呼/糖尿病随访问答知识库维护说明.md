# 糖尿病随访问答知识库维护说明

## 一、定位

本文件说明通义晓蜜“问答管理”中，糖尿病患者健康随访场景的高频问答知识库怎么维护。

问答知识库用于补充机器人在外呼过程中遇到的患者追问，例如“你是谁”“为什么给我打电话”“血糖偏高怎么办”“能不能帮我改药”等。它不是随访主流程本身，也不负责替代医生诊疗。

## 二、维护原则

- 问题要来自患者真实问法，避免写成长句说明。
- 一个知识点只回答一个问题，不把多个问题混在一起。
- 答案要短，适合电话播报，建议 1-3 句话。
- 医疗类答案要保守，不诊断、不调药、不承诺效果。
- 涉及异常症状、血糖明显异常、用药调整时，引导联系医生或健管师。
- 能用随访流程采集的信息，不放到 FAQ 里重复维护。

## 三、类目怎么创建

建议先在问答管理左侧类目树中手工创建类目，再导入 Excel。这样能避免 Excel 里类目路径写错后产生不一致的类目。

类目采用两级结构即可，不建议一开始建太深。

### 推荐类目结构

```text
糖尿病健康随访
糖尿病健康随访/身份与来电说明
糖尿病健康随访/随访流程说明
糖尿病健康随访/血糖监测
糖尿病健康随访/饮食运动
糖尿病健康随访/用药与安全边界
糖尿病健康随访/异常症状与风险提醒
糖尿病健康随访/人工服务与隐私
糖尿病健康随访/拒访与不方便接听
```

### 类目使用说明

| 类目 | 维护内容 |
| --- | --- |
| 糖尿病健康随访/身份与来电说明 | 你是谁、为什么打电话、是不是机器人、哪个机构委托 |
| 糖尿病健康随访/随访流程说明 | 随访需要多久、问哪些内容、不想回答怎么办 |
| 糖尿病健康随访/血糖监测 | 什么时候测血糖、没测怎么办、血糖偏高/偏低如何处理 |
| 糖尿病健康随访/饮食运动 | 饮食控制、主食、水果、运动执行相关常见追问 |
| 糖尿病健康随访/用药与安全边界 | 忘记吃药、能否停药/换药/加药等边界问题 |
| 糖尿病健康随访/异常症状与风险提醒 | 心慌、手抖、出冷汗、头晕、明显不适等情况 |
| 糖尿病健康随访/人工服务与隐私 | 是否会有人联系、信息是否保密、通话是否记录 |
| 糖尿病健康随访/拒访与不方便接听 | 现在不方便、以后再打、不想接听 |

## 四、Excel 导入模板字段

导入模板字段如下：

| 字段 | 是否必填 | 维护说明 |
| --- | --- | --- |
| 类目路径 | 是 | 用 `/` 表示多级类目，例如 `糖尿病健康随访/血糖监测` |
| 知识标题 | 是 | 主问题，建议写成患者真实问法，最多 120 字 |
| 相似问法 | 否 | 同一问题的不同问法，多条用换行分隔 |
| 生效日期 | 否 | 格式 `2019-01-14 11:50:45`，不填表示永久生效 |
| 失效日期 | 否 | 格式同上，不填表示不自动失效 |
| 答案（默认）【纯文本】 | 是 | 电话可直接播报的答案，建议短句 |

## 五、Excel 维护规范

### 类目路径

类目路径必须和左侧类目树完全一致。

推荐写法：

```text
糖尿病健康随访/血糖监测
```

不推荐写法：

```text
糖尿病/血糖/监测/空腹血糖/偏高
```

原因是类目太深后难维护，也容易在导入时写错路径。

### 知识标题

知识标题建议写成患者最可能问出来的话。

推荐：

```text
你们为什么给我打电话
```

不推荐：

```text
关于糖尿病患者智能外呼健康随访业务目的的说明
```

### 相似问法

相似问法用于提升命中率。同一个意思的问法放在同一条知识里，多条用换行。

示例：

```text
为什么打给我
这通电话是干嘛的
谁让你们联系我的
```

### 答案

答案要适合语音播报，不要太长。

推荐：

```text
这通电话是受您的健管师委托，做一次简短的糖尿病健康随访，主要了解您近期血糖监测和方案执行情况，方便健管师后续更好地跟进。
```

不推荐：

```text
本系统基于慢病管理全流程服务体系，结合患者历史档案、指标记录、干预方案和健康管理闭环机制，开展智能化外呼随访服务……
```

## 六、首期建议维护的问题

### 身份与来电说明

| 知识标题 | 相似问法方向 | 答案要点 |
| --- | --- | --- |
| 你是谁 | 你是什么人、你是机器人吗 | 说明是机构智能健康随访助手，受健管师委托 |
| 你们为什么给我打电话 | 为什么联系我、这通电话干嘛 | 说明是糖尿病健康随访，了解近期管理情况 |
| 这是哪个医院或机构 | 你们是哪儿的、谁委托的 | 说明机构名称和健管师委托，具体变量由主流程表达 |
| 这通电话要多久 | 需要说多久、会问很多吗 | 说明约 2-3 分钟，只问几个健康管理问题 |

### 血糖监测

| 知识标题 | 相似问法方向 | 答案要点 |
| --- | --- | --- |
| 我最近没测血糖怎么办 | 忘了测血糖、没有血糖记录 | 建议后续按计划监测，本次如实反馈 |
| 血糖偏高怎么办 | 血糖高了怎么办、最近血糖高 | 不诊断，建议继续监测，明显异常联系医生/健管师 |
| 血糖偏低怎么办 | 低血糖怎么办、血糖低了 | 如有不适及时处理并联系医生/健管师，严重不适及时就医 |
| 我需要每天测血糖吗 | 多久测一次、什么时候测 | 按医生或健管师计划执行，不清楚可请健管师确认 |

### 饮食运动

| 知识标题 | 相似问法方向 | 答案要点 |
| --- | --- | --- |
| 饮食没控制好怎么办 | 最近吃多了、没管住嘴 | 如实反馈，健管师会结合情况给后续建议 |
| 最近没运动怎么办 | 没时间运动、不想运动 | 记录执行困难，后续可由健管师协助调整 |
| 糖尿病能吃水果吗 | 能不能吃水果、吃什么水果 | 不给具体处方，提醒按方案控制量，有疑问问健管师 |

### 用药与安全边界

| 知识标题 | 相似问法方向 | 答案要点 |
| --- | --- | --- |
| 我能不能停药 | 可不可以不吃药、能减药吗 | 不建议自行停药或调药，需要咨询医生 |
| 忘记吃药怎么办 | 漏服药怎么办 | 不给补服方案，建议按医生交代处理，不清楚联系医生/健管师 |
| 药吃了不舒服怎么办 | 吃药后不适、副作用 | 记录情况，建议及时联系医生或健管师 |

### 人工服务与隐私

| 知识标题 | 相似问法方向 | 答案要点 |
| --- | --- | --- |
| 我想让健管师联系我 | 能不能人工回访、找医生 | 记录需求并反馈给健管师 |
| 我的信息会保密吗 | 隐私安全吗、会不会泄露 | 说明仅用于健康管理随访和服务跟进 |
| 我现在不方便 | 现在没空、以后再说 | 礼貌结束，记录不方便接听 |

## 七、不建议维护的内容

- 具体药物剂量调整。
- 个体化诊断结论。
- 复杂医学指南原文。
- 与本场景无关的医院挂号、收费、保险等泛客服问题。
- 需要医生判断的急症处理细节。

这类问题建议统一回答：机器人无法替代医生判断，会记录并反馈给健管师；如有明显不适或紧急情况，请及时就医。

## 八、和随访主流程的边界

主流程负责主动提问和采集信息，例如血糖监测、饮食运动用药执行、风险信号。

FAQ 负责回答患者临时追问，例如“你是谁”“为什么问这个”“我能不能停药”“现在不方便怎么办”。

如果一个问题会影响随访结果标签，例如“患者要求人工联系”“患者有低血糖症状”，FAQ 答案里要明确引导机器人记录对应标签，不能只回答完就结束。
